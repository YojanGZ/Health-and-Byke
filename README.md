## 📝 Descripción 

Facilitar el cuidado y mantenimiento de tu motocicleta por medio de una aplicación web minimalista y moderna que busca almacenar, registrar y seguir cada servicio técnico, con eficiencia y exactitud.

--- 

## ✨ Características principales 

- **Registro de motocicleta:** Añade la información de tu moto y manten su kilometraje actualizado (HU-01, HU-02).
- **Registro de servicios:** Guarda cada mantenimiento realizado (cambio de aceite, frenos, llantas, etc.) junto con detalles de taller y costos (HU-03, HU-04, HU-05).
- **Historial y seguimiento:** Lleva un control cronológico y detallado de la vida útil de tu moto. 
- **Alertas y recordatorios:** Define alertas por kilometraje para saber cuándo hacer los próximos mantenimientos (HU-06).

--- 

## 🛠️ Tecnologías utilizadas 

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla - nivel intermedio)
- **Iconos:** Phosphor Icons (CDN)
- **Almacenamiento:** `localStorage` para guardar datos en el navegador y brindar una experiencia realista sin necesidad de backend.

--- 

## 📁 Estructura del Proyecto 

Este repositorio se organiza de la siguiente manera: 

- `docs/`: Documentación del proyecto (Backlog, Historias de Usuario, Sprints). 
- `src/`: Código fuente de la aplicación.
  - `index.html`: Estructura principal de la aplicación web.
  - `css/style.css`: Hojas de estilo modernas, responsivas y minimalistas.
  - `js/app.js`: Lógica de la aplicación para manejar el DOM y `localStorage`.

---

## 🚀 Cómo ejecutar y visualizar el código

Para visualizar y editar este código:

1. **Clona este repositorio** o descarga los archivos.
2. Abre la carpeta del proyecto en **Visual Studio Code (VS Code)**.
3. Para visualizar la aplicación, puedes abrir directamente el archivo `src/index.html` en tu navegador.
4. **Recomendado:** Si usas VS Code, instala la extensión **Live Server**. Una vez instalada, haz clic derecho sobre el archivo `src/index.html` y selecciona **"Open with Live Server"**. Esto abrirá la aplicación en tu navegador predeterminado y actualizará los cambios automáticamente al guardar.
