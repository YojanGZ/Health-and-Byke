# Sprint 01: Core Garage & Maintenance (Health & Bike) 

  

## 📋 1. Sprint Backlog  

  

### 🎯 Objetivo del Sprint  

Permitir que el usuario pueda registrar su motocicleta en la aplicación **Health & Bike**, actualizar su kilometraje manualmente y llevar un registro básico del historial de mantenimientos. 

  

### 📝 Historias de Usuario Seleccionadas 

* **HU-01:** Como motociclista, quiero registrar mi moto ingresando marca, modelo, año y kilometraje actual, para que la app sepa qué vehículo estoy gestionando. *(Prioridad: Alta)* 

* **HU-02:** Como motociclista, quiero actualizar el kilometraje de mi moto manualmente, para que la app sepa cuánto la voy usando. *(Prioridad: Alta)* 

* **HU-03:** Como usuario, quiero registrar un mantenimiento realizado (ej. cambio de aceite, frenos) indicando fecha, tipo de servicio y costo, para tener una bitácora. *(Prioridad: Alta)* 

* **HU-04:** Como usuario, quiero registrar el nombre del taller y la ubicación/dirección donde se hizo el mantenimiento, para saber a dónde la llevé. *(Prioridad: Alta)* 

  

### 🛠️ Tareas Técnicas  

- [ ] Configurar la base de datos local para los modelos de `Bike` y `Maintenance`. 

- [ ] Desarrollar la interfaz (UI) para el formulario de registro de la motocicleta. 

- [ ] Desarrollar la interfaz (UI) para actualizar el kilometraje actual. 

- [ ] Desarrollar la pantalla de visualización y creación del historial de mantenimientos. 

  

### ✅ Definición de Hecho  

- Código escrito, revisado y probado localmente. 

- Interfaces funcionales para el registro de vehículos y mantenimientos. 

- Sin errores críticos en consola.
