# Historias de Usuario - HEALTH & BYKE 

  

Este documento contiene el detalle completo de las Historias de Usuario organizadas por Fases y Épicas. 

  

## FASE 1: El MVP 

Esta fase incluye lo mínimo indispensable para que un motociclista descargue la app, registre su moto y no se le olvide cambiar el aceite. 

  

### 1. Épica: Gestión del Garaje (Vehículos) 

* **HU-01:** Como motociclista, quiero registrar mi moto ingresando marca, modelo, año y kilometraje actual, para que la app sepa qué vehículo estoy gestionando. *(Prioridad: Alta)* 

* **HU-02:** Como motociclista, quiero actualizar el kilometraje de mi moto manualmente, para que la app sepa cuánto la voy usando. *(Prioridad: Alta)* 

  

### 2. Épica: Historial de Mantenimientos 

* **HU-03:** Como usuario, quiero registrar un mantenimiento realizado (ej. cambio de aceite, frenos) indicando fecha, tipo de servicio y costo, para tener una bitácora. *(Prioridad: Alta)* 

* **HU-04:** Como usuario, quiero registrar el nombre del taller y la ubicación/dirección donde se hizo el mantenimiento, para saber a dónde la llevé. *(Prioridad: Alta)* 

* **HU-05:** Como usuario, quiero registrar el nombre del mecánico que me atendió, para tenerlo fichado. *(Prioridad: Media)* 

  

### 3. Épica: Sistema de Recordatorios Básicos por Desgaste 

* **HU-06:** Como usuario, quiero configurar un recordatorio basado en kilometraje para piezas críticas (ej. "Avisarme a los 3,000 km para cambio de aceite"). *(Prioridad: Alta)* 

* **HU-07:** Como usuario, quiero recibir una notificación push en mi celular cuando mi moto alcance el kilometraje o fecha límite de un mantenimiento. *(Prioridad: Alta)*

## FASE 2: Experiencia de Usuario y Mejoras 

  

### 4. Épica: Gestión de Perfil y Autenticación 

* **HU-08:** Como usuario, quiero registrarme con mi correo y contraseña para que mis datos y los de mi moto no se pierdan si cambio de celular. *(Prioridad: Media)* 

* **HU-09:** Como usuario, quiero iniciar sesión con Google o Apple para un acceso más rápido. *(Prioridad: Baja)* 

  

### 5. Épica: Historial Avanzado (Facturas y Archivos) 

* **HU-10:** Como usuario, quiero adjuntar una foto de la factura o recibo físico a cada registro de mantenimiento, para tener el respaldo digital de la garantía. *(Prioridad: Media)* 

  

### 6. Épica: Directorio de Talleres y Favoritos 

* **HU-11:** Como usuario, quiero guardar talleres en una lista de "Favoritos" para seleccionarlos rápidamente cuando registre un nuevo mantenimiento. *(Prioridad: Media)* 

* **HU-12:** Como usuario, quiero calificar con estrellas (1 a 5) al taller o mecánico después de un servicio, para recordar cuáles me gustaron más. *(Prioridad: Baja)*

## FASE 3: Analítica y Expansión 

Funciones avanzadas para cuando tu app ya tenga usuarios activos. 

  

### 7. Épica: Estadísticas y Reportes 

* **HU-13:** Como usuario, quiero ver un gráfico de cuánto dinero he gastado en mi moto al mes o al año. *(Prioridad: Baja)* 

* **HU-14:** Como usuario, quiero exportar todo el historial de mi moto en un PDF ordenado, por si decido venderla y mostrarle al comprador que estuvo bien cuidada. *(Prioridad: Baja)*
